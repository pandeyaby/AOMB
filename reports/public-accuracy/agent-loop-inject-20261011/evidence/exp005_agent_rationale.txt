Domain justification.** HDFS block logs are highly templated, so a model that has converged tightly makes dropped, duplicated, reordered and novel-value corruptions stand out as high-surprise tokens. At 2**15 tokens per step, each step takes one 16×2048 micro-batch. Halving the batch roughly doubles the number of optimizer steps in the same wall-clock time.

**5. Risk.** Gradient noise is higher, and the smaller device batch may lower throughput slightly. Memory use drops, so there is no OOM risk. The assertion holds.

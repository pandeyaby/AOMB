# Support

Where strangers get help for **AOMB** — keep it short and honest.

## Verify first (no Mac / no keys)

Before opening an issue or PR, prove the public gates:

- Index: [`docs/public-wins.md`](docs/public-wins.md)
- 60s cheatsheet: [`docs/stranger-60s.md`](docs/stranger-60s.md)
- Share / paste snip: [`docs/share-snip.md`](docs/share-snip.md)

Cite a green [`stranger-verify`](https://github.com/pandeyaby/AOMB/actions/workflows/stranger-verify.yml) run when you can.

## Security / vulns

Report via [`SECURITY.md`](SECURITY.md) — **not** a public issue with exploit details.

## Contributing / PRs

- Short pointer: [`CONTRIBUTING.md`](CONTRIBUTING.md)
- Outsider path: [`docs/contributing-stranger.md`](docs/contributing-stranger.md)
